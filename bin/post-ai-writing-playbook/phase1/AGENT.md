# Phase 1　DEV英語記事の比較

保存されたDEVの記事を使い、2018〜2021年と2023〜2024年の英語記事の文章量・文のリズム・書式の差を測る。語彙、語り口、構造、内容記述、記事構成の変化と時期を探索し、条件による違いを日本語の執筆材料にまとめる。

## 開始と再開

1. [全体の指示](../AGENT.md)と[再開手順](phase1-handoff.md)を開く。runのプロファイルとD02の完了証拠を確認する。
2. [測定仕様](measurement-spec.md)と[分析方法](analysis-methods.md)を読む。過去の件数や結果は現在のrunの期待値に使わない。
3. パッケージルートで `python3 workflow.py next` を実行する。対象leafの指示を開き、`python3 workflow.py start ID --owner NAME` が返す試行ディレクトリで作業する。
4. 当該runと依存タスクの合格済み試行パスをstatusから解決し、実ファイルのSHA-256を照合する。leaf同士は生産物や作業ファイルを共有書き込みしない。
5. 実装・実測と別系列の検証を完了させる。集計本文から検証結果を転記するだけの検査は使わない。別担当が入力と成果物を読んで独立に確認した範囲を `verification.json` に記す。
6. run ID、タスクID、試行、プロファイル、受入条件ごとの証拠と成果物のSHA-256を `receipt.json` に記す。 `python3 workflow.py finish ID --evidence <receiptの相対パス>` を実行する。

全量プロファイルでも、先に固定5候補で抽出・判定・保存・再読取を通す。5件の動作確認後に固定入力全件へ進む。probeだけを実行した段階では、試行を進行中のままにし、確認できた範囲をcheckpointに残す。

## 依存関係

| タスク | 直接の依存 |
| --- | --- |
| T00 / T01 / T02 / T03 | それぞれ D02 / T00 / T01 / T02 |
| A01〜A05、A08 | T03 |
| A06 | T03、A04 |
| A07 | T03、A05 |
| A09 | A01〜A08 |
| A10 | A01、A02、A03、A09 |
| A11 | T03、A06、A07、A08 |
| A12 | T03、A01、A02、A03、A05、A09 |
| V01 | A01〜A12 |
| R01 | T03、A01〜A12、V01 |

T03からA01〜A05とA08を並行実行できる。A04からA06、A05からA07を開始する。A09、A10、A11、A12は直接依存が揃った順に実行する。V01が条件を変えた比較を受け持ち、R01が日本語の執筆材料を確定する。

比較値には対象年、記事と既知著者のn、計算不能理由、単位と対象集合を添える。探索と主比較を区別する。条件が不足した場合は指定された行を理由付きで保存する。実行不能や実装失敗を支持不足へ置き換えて完了させない。記事本文・盲検対応表・抜粋はローカルの実行成果物に置く。
